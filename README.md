# Анализ успеваемости студентов IT-курса

## О проекте

Исследовательский анализ данных (EDA) студентов, проходящих обучение по IT-направлению.  
**Цель** - выявить факторы, влияющие на успеваемость.

**Датасет:** 77 записей абитуриентов из разных стран

## Ключевые вопросы

1. Влияет ли предыдущее образование на время подготовки?
2. Есть ли связь между временем подготовки и баллами Python/DB?
3. Различаются ли результаты в зависимости от пола и страны?
4. Есть ли выбросы в данных?

## Основные выводы

**Корреляция studyHOURS с Python** Сильная положительная связь (0.81). Чем больше часов подготовки, тем выше баллы. 

**Корреляция entryEXAM с Python** Также сильная (0.79). Вступительный экзамен - хороший предиктор успеха. 

**Образование** Студенты с магистратурой учатся в среднем на 25% дольше, чем студенты со школьным образованием. 

**Гендер** Женщины показывают немного более высокие баллы по Python (средний 76 против 74 у мужчин). 

**Пропуски** Только 2 пропуска в колонке Python - данные достаточно чистые.
